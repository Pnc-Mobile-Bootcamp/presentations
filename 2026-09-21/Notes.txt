Getting set up for Kotlin in VS Code:

1. Install the Java Development Kit (JDK)
	- many to choose from, we recommend https://aws.amazon.com/corretto/


2. Install the Kotlin standalone compiler:  https://github.com/JetBrains/kotlin/releases
	- download the .zip file
	- extract the contents to a safe, permanent location (e.g. c:\kotlinc )
	- use File Explorer to drill down into the "bin" folder and copy the path
	- add that location to your OS Path Environment variable

3. Install VS Code: https://code.visualstudio.com/

	Two plugins:
	- Kotlin extension - by JetBrains
	- Code Runner - by Jun Han




When building an entire app, you would create .kt files 
(many can be compiled into one program)
and one of the files would have a main() function 
(entry point into the application)
