
If you are going to create AndroidTest UI tests for legacy xml-based views:

Android has 3 system-wide animation settings in Developer Options

- Window animation scale
- Transition animation scale
- Animator Duration scale

(all default to 1x speed)


On the phone (or emulator)
1. enable Developer options: Settings -> About phone -> tap Build Number seven times
2. Go to Settings -> System -> Developer options
3. Under the Drawing section, you'll see all three animation settings - set each to "Animation off"
