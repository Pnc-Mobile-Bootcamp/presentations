What is a hash?

A hash is a fixed size binary representation of some digital content.
- two hashes of the same digital content will be the same
- small difference in the digital content will result in a large difference in the hash





A hashing algorithm is a function that:

- Chaotic functions - a small difference in the input makes a large difference in the output
- other category of functions - create a fixed size output no matter the size of the input
- any two random inputs have a vanishingly small chance of producing the same output
