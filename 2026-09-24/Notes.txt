Hash is a fixed-size binary chunk that is computed from some other binary content
- hash is the same size no matter the size of the original content 
- if even one bit of the original content is changed, the hash is changed drastically
- the odds of any two random original content creating the same hash is vanishingly small
- every time you input the same original content, you get the same hash



Public/Private key encryption

public and private keys are numbers that are mathematically related to each other
- if you have one of those numbers, there is no realistic way to figure out what the other one is

they are used together with encryption functions
- any content that is encrypted using one of the keys can only be decrypted by the other
